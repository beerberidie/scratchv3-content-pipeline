WordPress Integration Info

How to Set Up WordPress Integration

  1. Log into your WordPress admin dashboard
  2. Go to Users > Profile
  3. Scroll down to "Application Passwords"
  4. Create a new application password for this app
  5. Copy the generated password and paste it above
  6. Add your WordPress site URLs to the presets

Note: Generated content will be posted as drafts to your WordPress site.
